# Disclaimer

**This registry is not an official source for any accreditation framework.**

The files under `frameworks/` are a convenience transcription of published
accreditation manuals — NBA, NAAC, ABET, NIRF and others. They are maintained by
academics, in good faith, from public documents. They are not issued, endorsed,
reviewed or approved by any accreditation body.

## Before you rely on this for a submission

Verify every outcome statement, criterion and parameter against the official
manual from the accrediting body. Statement text is reproduced **verbatim in a
Self-Assessment Report**, so a paraphrase, a transcription slip, or a file that
has not caught up with a revision is a defect in your submission — not merely an
inconvenience.

Each framework file carries `source_document`, `source_url`, `retrieved_on` and
`verified_on`. Read those fields. The README shows a badge derived from the
oldest `verified_on` across the whole registry, so staleness is visible rather
than silent — but a badge is not a substitute for checking the manual.

## Frameworks change, and they change without warning us

NBA moved from twelve programme outcomes to eleven under GAPC v4.0. NAAC retired
CGPA grading in favour of Binary accreditation with Maturity-Based Graded Levels.
Both happened on the accrediting body's timetable, not ours. There will be a
period after any future revision during which this registry is wrong, and we may
not know it yet.

This is why every framework file is versioned and why nothing is ever edited in
place: a superseded version stays published so that historical evidence computed
under it remains readable and reproducible. Pin a version. Do not float.

## Reporting an error

An incorrect framework file is the most serious defect this project can have.
Report it as a GitHub issue, or privately per `SECURITY.md` if you believe it is
being relied upon. Include the official document and the page or clause. See
`CONTRIBUTING.md` — every correction must cite its source.
